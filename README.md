# Exegol CTF – Write-ups Boot2Root

Write-ups de **12 machines Boot2Root** compromises lors du CTF Exegol du Bachelor Epitech (spécialisation cybersécurité), depuis l'environnement offensif [Exegol](https://github.com/ThePorgs/Exegol).

Pour chaque machine : périmètre et objectif, reconnaissance, exploitation pour obtenir un accès utilisateur (`user.txt`), puis élévation de privilèges jusqu'à `root.txt` quand le challenge le demandait.

> **Note :** les flags (`EPI{…}`) et les mots de passe découverts sont volontairement masqués pour ne pas gâcher le CTF aux autres étudiants. Contenu à but pédagogique, réalisé sur une infrastructure d'entraînement dédiée.
